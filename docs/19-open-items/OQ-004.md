# Open Question

## Question
When should checklists (sub-task lists within a card) be prioritized as a feature, and should they be modeled as a new `DB-CHECKLIST-ITEM` table or embedded as structured content on the card?

## Why It Matters
Checklists are one of the most commonly requested Trello-style features beyond v1 core scope; the data model choice affects future migration cost.

## Options / Evidence
