# Stakeholders

| Role | Responsibility | Primary Interest |
|---|---|---|
| Product Owner | Owns scope, priority, acceptance of features | Fast adoption, clear core workflow |
| Engineering Lead | Owns technical architecture and delivery | Maintainable, realtime-capable, well-tested system |
| Frontend Engineers | Build React SPA, board/card UI, drag-and-drop | Clear screen/API contracts |
| Backend Engineers | Build Node.js API, WebSocket layer, database schema | Clear API/DB contracts, concurrency rules |
| QA / Test Engineers | Validate acceptance criteria and regression coverage | Clear acceptance criteria and test cases |
| End Users (Workspace members) | Use the product to organize and track work | Fast, reliable, intuitive drag-and-drop board experience |
| Workspace Admins | Manage team membership and workspace settings | Clear role/permission model |
