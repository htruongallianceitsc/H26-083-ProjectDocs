Prompt 33 — Ready Gate Review

Before creating or submitting an implementation WorkPlan:

  • Resolve the target Feature.
  • Read its direct related entities.
  • Run documentation validation and the Ready gate.
  • If the gate fails, remediate documentation rather than bypassing the check.
  • Report every failed condition with the exact entity/status/relation causing it.
  • Only proceed to WorkPlan authoring when Ready passes.
