Brownfield Reverse Engineering

When onboarding an existing project, do not infer canonical business truth directly from filenames. Use source evidence to build an inventory and candidate graph, review confidence and boundaries, then promote only accepted candidates. Reconcile docs against source before creating the initial brownfield baseline. If normalization is desired, create a refactor plan and reviewed WorkPlan; never move source automatically from heuristic analysis.
