Prompt 36 — Impact Analysis

Run graph impact analysis for the target entity before proposing edits. Prioritize HIGH impact results, explain the typed relation path that creates the potential impact, and identify which canonical documents/tests should be reviewed. Do not infer dependencies from filenames alone.
