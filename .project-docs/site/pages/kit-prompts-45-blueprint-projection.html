Prompt 45 — Blueprint Projection

Use when creating or refreshing a project from one Blueprint file.

  • Read PROJECT_BLUEPRINT.md and kit/registry/blueprint-profiles.json.
  • Preserve ownership: inline content may become candidates; linked content must be summarized from canonical docs.
  • Never create/overwrite canonical documents without a reviewed promotion step.
  • Select both a detail profile (overview|lightweight|standard|full) and audience (general|business|developer|qa).
  • When compiling from docs, use entity metadata, relations and verification evidence; do not invent missing relationships.
  • Report stale/conflicting ownership before reconciliation.
  • Prefer linked canonical documents when automatically reconciling.
