Prompt 11 — Architecture & Integrations

Review project/feature và document technical architecture cần thiết:
- system context
- frontend/backend boundaries
- caching
- queue/background jobs
- file storage
- realtime
- external integrations
- resilience: timeout/retry/circuit breaker/idempotency

Nếu có decision đáng kể, tạo ADR thay vì chỉ ghi trong architecture doc.
Nêu trade-off và consequences; không giả định hạ tầng chưa confirmed.
