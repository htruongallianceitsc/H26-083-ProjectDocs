Workflow 04 — Functional -> Technical Contracts

Steps

  • Từ Screen/Flow, xác định API interaction.
  • Tạo API contract từng endpoint.
  • Từ API/business state, thiết kế DB objects.
  • Document transaction, concurrency, idempotency, retry.
  • Xác định external integrations/background jobs.
  • Ghi architecture decisions đáng kể bằng ADR.
  • Cập nhật Blueprint.

Exit Gate

Mỗi feature có technical contract đủ rõ để FE/BE/DB làm song song mà không tự mâu thuẫn.
