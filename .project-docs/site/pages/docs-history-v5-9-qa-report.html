v5.9 Blueprint E2E assertions

  • one PROJECT_BLUEPRINT.md creates candidates for Module, Feature, Requirement and Test Case seed rows;
  • promotion is blocked behind explicit accepted reviews;
  • accepted candidates are promoted to canonical Markdown under the expected folders;

  • older E2E workspaces without PROJECT_BLUEPRINT.md remain compatible.
