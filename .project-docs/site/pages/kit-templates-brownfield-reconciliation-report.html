Brownfield Reconciliation Report

The reconciliation report compares reviewed source evidence with canonical docs before a brownfield baseline is accepted.

Required checks

  • Existing Application boundaries are registered.
  • Inventory and candidates are current.
  • High-confidence candidates have been reviewed.
  • Accepted candidates have been promoted to canonical docs.
  • Evidence files still exist.
  • No high-severity mismatch remains unresolved.
  • A baseline is created only after the Brownfield Baseline Gate passes.
