Workflow 10 — Mobile Readiness

Áp dụng khi projectTypes có mobile.

Required passes

  • Architecture + state ownership.
  • App lifecycle + process death/resume.
  • Network resilience + offline/sync.
  • Storage migration/logout cleanup.
  • Permission/native capability.
  • Navigation/deep link/push contract.
  • Realtime/background work nếu có.
  • Mobile security/privacy + SDK inventory.
  • UI states/accessibility/performance budgets.
  • Device/OS/network/lifecycle test matrix.
