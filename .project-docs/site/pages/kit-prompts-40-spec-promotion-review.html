Prompt 40 — Promote Specification Depth

Review a Feature that is moving from Lightweight → Standard or Standard → Full.

  • Run/read the spec:promote gap report.
  • Re-read current Feature and relevant project context.
  • Add only missing canonical documentation needed by the target profile.
  • Preserve Feature code and existing relations/provenance.
  • Do not invent requirements to satisfy a numeric gate.
  • Resolve or explicitly retain Open Questions.
  • Re-run spec:check, Ready gate, freshness/impact as appropriate.
  • Apply the promoted spec_level only when target-level gaps are cleared.
