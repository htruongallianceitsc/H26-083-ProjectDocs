Prompt — Mobile Readiness Review

Review tài liệu mobile hiện có dựa trên toàn bộ kit/standards/project-types/mobile/ và stack mobile được chọn.

Output theo P0/P1/P2, nhưng mỗi finding phải có:

  • Evidence file/code.
  • Standard bị thiếu/vi phạm.
  • Impact.
  • Tài liệu/entity cần tạo hoặc cập nhật.
  • Test/release gate liên quan.

Bắt buộc kiểm: lifecycle, offline/sync, storage migration, permission, deep link, push, realtime, background, device matrix, security/privacy, performance, observability, store release, old binary/API compatibility.
