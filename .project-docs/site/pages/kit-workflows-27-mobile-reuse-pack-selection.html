Workflow 27 - Mobile Reuse Pack Selection

  • Identify actual project capabilities from approved scope.
  • Map each concern to Standard vs Capability Pack vs Pattern Pack.
  • pack:list and preview the selected pack.
  • Review variables, optional features and destination conflicts.
  • Apply import, then review imported canonical docs.
  • Resolve project-specific Open Questions/ADRs.
  • Approve pack review.
  • Continue Ready Gate / WorkPlan flow.

Do not use pack import as code generation. Packs seed reviewed documentation contracts only.
