Prompt 14 — Security Review

Review project docs và tạo/cập nhật security documentation.

Kiểm tra:
- authentication/session/token
- authorization/role/permission
- sensitive data classification
- encryption in transit/at rest
- secrets management
- audit trail
- input validation
- file upload/download risks
- rate limiting/abuse
- privacy/retention/deletion
- production access

Không ghi secret value thật. Tạo Security Open Questions khi thiếu policy.
