Workflow 05 — Quality & Test

Steps

  • Tạo NFR áp dụng cho project/feature.
  • Chuyển Requirement/Rule thành Acceptance Criteria.
  • Tạo happy path, validation, permission, error, concurrency, boundary test cases.
  • Link Test Case -> Requirement/Business Rule.
  • Audit coverage.

Exit Gate

  • Requirement approved phải có test coverage.
  • Business Rule critical phải có positive + negative test.
  • API error/permission paths không bị bỏ quên.
