Prompt - Pattern Pack Design

Create a reusable Pattern Pack for a repeated structural workflow without pretending business semantics are universal. Keep TODOs/open questions explicit, parameterize names/routes/API prefixes, preserve stable relationship shape, include minimum test categories, and set upgradePolicy to fork unless there is a strong reason to track upstream.
