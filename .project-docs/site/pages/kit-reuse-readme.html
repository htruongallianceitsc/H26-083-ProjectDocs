Reuse Library

Reusable assets are grouped by reuse strength:

  • capabilities/ — versioned capability packs that carry a coherent reusable functional baseline.
  • patterns/ — lighter structural patterns for repeated shapes with project-specific semantics.
  • templates/ — reusable authoring/package templates.

Project imports remain governed by .project-docs/packs.lock.json, review status, and the reuse policy in kit/registry/reuse-policy.json.
