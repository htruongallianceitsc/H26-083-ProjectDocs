Workflow 03A - Reuse and Capability Detection

Run this after Scope/Blueprint and before detailed Module/Feature decomposition.

  • Inventory proposed capabilities/modules.
  • Run npm run pack:list from tools/.
  • Compare each capability to available Capability/Pattern Packs.
  • For a new repeated candidate, run npm run reuse:assess -- ... with observed evidence.
  • Choose:
  • existing Capability Pack -> preview import;
  • existing Pattern Pack -> preview import then complete project-specific TODOs;
  • no suitable pack -> generate from applicable Standards.
  • Record the decision using kit/templates/reuse/reuse-assessment-template.md when material.
  • Continue to Module/Feature decomposition only after reuse choices are understood.

Never create a new pack merely to avoid writing one project-specific feature.
