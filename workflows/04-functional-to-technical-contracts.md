# Workflow 04 — Functional -> Technical Contracts

## Steps
1. Từ Screen/Flow, xác định API interaction.
2. Tạo API contract từng endpoint.
3. Từ API/business state, thiết kế DB objects.
4. Document transaction, concurrency, idempotency, retry.
5. Xác định external integrations/background jobs.
6. Ghi architecture decisions đáng kể bằng ADR.
7. Cập nhật Blueprint.

## Exit Gate
Mỗi feature có technical contract đủ rõ để FE/BE/DB làm song song mà không tự mâu thuẫn.
