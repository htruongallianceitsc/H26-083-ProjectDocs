# Workflow 06 — Production Readiness

## Areas
- Authentication & authorization.
- Data security/privacy/audit.
- Environment/configuration/secrets.
- CI/CD/deployment/rollback.
- Database migration/backup/restore.
- Logging/metrics/tracing/alerts.
- Performance/capacity.
- Incident response/runbooks.
- Scheduled jobs/external dependencies.

## Exit Gate
Một on-call engineer mới phải biết cách phát hiện, chẩn đoán và xử lý các failure mode chính mà không phụ thuộc người build feature ban đầu.
