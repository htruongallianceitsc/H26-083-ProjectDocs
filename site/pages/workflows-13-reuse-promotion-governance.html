Workflow 13 - Reuse Promotion Governance

Use periodically across the project portfolio.

  • Collect capabilities repeated across projects.
  • Measure similarity and local overrides.
  • Run the reuse assessment tool.
  • Promote Standard -> Pattern Pack when structure repeats.
  • Promote Pattern Pack -> Capability Pack only when semantics are stable and upgrade ROI is positive.
  • Assign pack owner and review cadence.
  • Validate the pack and run a clean import into a disposable workspace.
  • Publish semantic version and changelog.
  • On breaking change, increment major version and document migration/upgrade implications.
  • Demote or retire packs that create more conflicts than reuse value.
