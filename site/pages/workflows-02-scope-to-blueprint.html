Workflow 02 — Scope -> Project Blueprint

Steps

  • Phân rã domain thành Module.
  • Phân rã mỗi Module thành Feature.
  • Lập inventory Screen/Route sơ bộ.
  • Lập inventory API sơ bộ.
  • Lập inventory DB object/integration sơ bộ.
  • Đánh dấu unknown thay vì tự thiết kế quá sớm.
  • Điền PROJECT_BLUEPRINT.md.

Exit Gate

  • Mọi capability in-scope phải map được vào ít nhất một Feature.
  • Mọi Feature phải thuộc đúng một Module.
  • Không dùng Module như container cho API/DB/Test.
