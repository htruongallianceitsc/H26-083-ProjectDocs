Prompt - Reuse Promotion Review

Review an existing feature/module used across projects and decide whether it should remain Standard-only, become a Pattern Pack, or become a Capability Pack.

Evaluate project count, similarity, semantic stability, number of local overrides, security/cross-cutting value, maintenance cost, upgrade-conflict risk and ownership. Use registry/reuse-policy.json as the default policy, but document justified exceptions as an ADR.
