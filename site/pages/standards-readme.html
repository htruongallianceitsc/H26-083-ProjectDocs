Standards Architecture v4.1

Standards are resolved in this order:

  • Core Governance - always applicable.
  • Project Type - Web, Mobile and/or API.
  • Technology Stack - ReactJS, React Native, Flutter, NodeJS API, ASP.NET Core API, PostgreSQL, etc.
  • Capability Standard - cross-project rules such as Authentication.
  • Project ADR/Exception - explicit project-specific deviation.

Standards define rules. They do not become unnecessary when a Capability Pack is used; packs must still comply with applicable standards.
