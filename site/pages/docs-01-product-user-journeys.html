User Journeys

Journey 1 — First-time onboarding

  • User registers an account (FEAT-AUTH-REGISTER).
  • User creates their first Workspace (FEAT-WORKSPACE-CREATE).
  • User creates a Board inside the Workspace (FEAT-BOARD-CREATE), which is seeded with default Lists ("To Do", "In Progress", "Done").
  • User creates their first Card (FEAT-CARD-CREATE) and drags it across Lists as work progresses (FEAT-CARD-MOVE).

Journey 2 — Daily usage

  • User opens a Board they are a member of.
  • User scans Cards assigned to them (via member avatar), opens a Card to read/add a comment (FEAT-COMMENT-ADD).
  • User drags the Card to the next List as status changes (FEAT-CARD-MOVE).
  • User marks the Card done by moving it to the "Done" list, then archives it later during board cleanup (FEAT-CARD-ARCHIVE).

Journey 3 — Team setup

  • Workspace admin invites teammates by email (FEAT-WORKSPACE-MANAGE-MEMBERS).
  • Board owner creates Lists matching the team's workflow (FEAT-LIST-MANAGE) and defines Labels (FEAT-LABEL-MANAGE).
  • Teammates are assigned to Cards (FEAT-MEMBER-ASSIGN-CARD) as work is planned.
