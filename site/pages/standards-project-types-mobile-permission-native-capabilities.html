Permission Native Capabilities

Required standard

Every camera/photo/location/notification/biometric capability must document purpose, granted/denied/revoked/limited states and settings fallback.

Documentation expectation

Record project decisions, deviations, measurable acceptance criteria and tests. Do not leave framework defaults implicit.
