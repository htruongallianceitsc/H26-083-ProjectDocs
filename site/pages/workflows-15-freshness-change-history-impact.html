Workflow 15 — Freshness, Impact, ChangeSet and Baseline

Use when

A reviewed feature/requirement/API/business rule changes, or before UAT/release snapshots.

Flow

Change request / edit intent
        ↓
Impact analysis
        ↓
Update canonical docs
        ↓
Freshness check
        ↓
Review affected docs
        ↓
Reconcile stale documents
        ↓
Ready / Done gate
        ↓
ChangeSet scan
        ↓
Optional Baseline at milestone

Steps

  • Run npm run impact -- --entity <CODE> before a material change.
  • Update canonical project documentation.
  • Run npm run doc:check or target the affected Feature.
  • Review every STALE dependency result; update documentation when needed.
  • Run doc:reconcile only after that review.
  • Rerun Ready/Done and npm run qa.
  • Record the batch with changeset:scan.
  • Create a named baseline for UAT/release/migration boundaries.
