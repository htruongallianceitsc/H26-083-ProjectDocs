Register with duplicate email is rejected

docs/11-quality/test-cases/TC-AUTH-REGISTER-001.md

Test Case

Objective

Verify registration enforces email uniqueness and password policy.

Verifies

REQ-AUTH-001, BR-AUTH-001, API-AUTH-REGISTER

Preconditions

An account with email jane@example.com already exists.

Test Data

{ "email": "jane@example.com", "password": "Passw0rd", "displayName": "Jane 2" }

Steps

#ActionExpected Result
1POST /api/auth/register with the test data above409 EMAIL_ALREADY_EXISTS
2POST with a unique email but password "short1"400 VALIDATION_ERROR
3POST with a unique email and password "Passw0rd"201 Created, session returned

Postconditions

Exactly one new user row created (step 3 only).

Priority

P0

Automation Candidate

Yes — API integration test.

Notes

None.
