Source Bootstrap

For a new application: resolve the Source Profile, validate the selected Source Base, materialize it with source:init, create/verify the Application entity, confirm .project-docs/source.lock.json, run source:check, then link relevant Features to the Application. Do not add domain features that are not already documented.
