Workflow 07 — Change Management

Khi có yêu cầu thay đổi

  • Capture change request + reason.
  • Xác định entity canonical cần đổi.
  • Trace incoming/outgoing relations.
  • Phân tích potential impact.
  • Update docs canonical.
  • Reconcile Screen/API/DB/Test/Runbook liên quan.
  • Tạo ADR nếu decision đáng kể.
  • Update Blueprint/Traceability/Changelog.
  • Review Ready gate trước implementation.
  • Sau release, review Done gate.

Không làm

  • Sửa feature rồi quên test.
  • Sửa API path nhưng Blueprint vẫn cũ.
  • Rewrite ADR cũ để hợp lý hóa quyết định mới.
  • Copy cùng rule vào nhiều file.
