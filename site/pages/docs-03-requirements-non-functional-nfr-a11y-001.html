Keyboard-Accessible Core Interactions

docs/03-requirements/non-functional/NFR-A11Y-001.md

Non-Functional Requirement

Category

Accessibility

Requirement

Core interactions must have a usable non-pointer (keyboard) path, since drag-and-drop alone is not accessible to all users.

Metric

Presence of a keyboard-operable alternative for each pointer-only interaction.

Target

Card move has a keyboard-accessible "Move to..." menu alternative to pointer drag-and-drop (see SCR-BOARD accessibility note). All forms are fully operable via keyboard with visible focus states.

Measurement Method

Manual accessibility review using keyboard-only navigation before release.

Scope

SCR-BOARD and all form-based screens.

Failure Threshold

Any core flow (login, create board, move a card) that cannot be completed via keyboard alone blocks release.

Verification / Test

Manual keyboard-only walkthrough of the core user journeys (docs/01-product/user-journeys.md) before release.
