Prompt 34 — WorkPlan and Task Generation

For a Ready Feature:

  • Scaffold the WorkPlan from current documentation context.
  • Replace generic scaffold tasks with a deterministic, reviewable implementation breakdown where needed.
  • Add assumptions, risks, acceptance criteria and explicit dependencies.
  • Keep each Task linked to canonical Feature/Requirement/Screen/API/DB/Test/Request entities.
  • Do not copy business rules into task text.
  • Mark authoring complete only after the plan is coherent.
  • Submit the plan to capture context hash.
  • Require review/approval.
  • If approval reports STALE_CONTEXT, re-read docs and refresh/re-author; never force approval.
  • Materialize Tasks only from the approved, non-stale plan.
