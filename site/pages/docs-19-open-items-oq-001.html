docs/19-open-items/OQ-001.md

Open Question

Question

Will KanbanFlow ever need a billing/subscription model (e.g. per-seat pricing, workspace tiers), and if so, what does that imply for the Workspace/Membership data model now?

Why It Matters

Retrofitting billing boundaries onto an existing Workspace model later could require data migration; worth flagging even if not acted on now.

Options / Evidence

No current product requirement for monetization; MVP is scoped as a free, self-serve tool.

Owner
