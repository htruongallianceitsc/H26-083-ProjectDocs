Workflow 05 — Quality & Test

Steps

  1. Tạo NFR áp dụng cho project/feature.
  2. Chuyển Requirement/Rule thành Acceptance Criteria.
  3. Tạo happy path, validation, permission, error, concurrency, boundary test cases.
  4. Link Test Case -> Requirement/Business Rule.
  5. Audit coverage.

Exit Gate

  • Requirement approved phải có test coverage.
  • Business Rule critical phải có positive + negative test.
  • API error/permission paths không bị bỏ quên.
