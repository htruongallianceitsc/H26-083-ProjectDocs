Workflow 11 — Store Release Readiness

  • Freeze version/build + API compatibility window.
  • Verify minimum supported version/maintenance mode/feature flags.
  • Verify signing/certificate/provisioning ownership.
  • Review Apple/Google privacy declarations against SDK/data inventory.
  • Run device/OS matrix + deep link/push/permission/background smoke.
  • Upload crash symbols/source maps.
  • Verify staged rollout, kill switch, hotfix path.
  • Monitor crash-free/ANR/startup/error/version adoption after rollout.
