## Evidence checklist

- Source files belong to the same business/technical responsibility.
- Suggested entity type is correct.
- Candidate does not duplicate an existing canonical entity.
- Suggested relations are supported by source evidence or existing docs.
- Any uncertainty is recorded before promotion.
