# Workflow 26 - React Native Production Readiness

1. Configure mobile/react-native profile.
2. `npm run profile:check`.
3. Review dependency baseline and `npm run source:dependency-check`.
4. Choose required capability/pattern packs; preview imports before applying.
5. Author Screen/API/mobile-runtime contracts.
6. Run `docs:validate`, `gate:ready` and `source:check`.
7. Scaffold/review WorkPlan.
8. Implement manually or with a separately governed implementation agent. This workflow does not generate feature code.
9. Reconcile docs/tests and pass Done Gate.
