# Workflow 11 — Store Release Readiness

1. Freeze version/build + API compatibility window.
2. Verify minimum supported version/maintenance mode/feature flags.
3. Verify signing/certificate/provisioning ownership.
4. Review Apple/Google privacy declarations against SDK/data inventory.
5. Run device/OS matrix + deep link/push/permission/background smoke.
6. Upload crash symbols/source maps.
7. Verify staged rollout, kill switch, hotfix path.
8. Monitor crash-free/ANR/startup/error/version adoption after rollout.
