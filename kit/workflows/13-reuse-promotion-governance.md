# Workflow 13 - Reuse Promotion Governance

Use periodically across the project portfolio.

1. Collect capabilities repeated across projects.
2. Measure similarity and local overrides.
3. Run the reuse assessment tool.
4. Promote Standard -> Pattern Pack when structure repeats.
5. Promote Pattern Pack -> Capability Pack only when semantics are stable and upgrade ROI is positive.
6. Assign pack owner and review cadence.
7. Validate the pack and run a clean import into a disposable workspace.
8. Publish semantic version and changelog.
9. On breaking change, increment major version and document migration/upgrade implications.
10. Demote or retire packs that create more conflicts than reuse value.
