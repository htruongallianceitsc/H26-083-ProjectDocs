# Workflow 27 - Mobile Reuse Pack Selection

1. Identify actual project capabilities from approved scope.
2. Map each concern to Standard vs Capability Pack vs Pattern Pack.
3. `pack:list` and preview the selected pack.
4. Review variables, optional features and destination conflicts.
5. Apply import, then review imported canonical docs.
6. Resolve project-specific Open Questions/ADRs.
7. Approve pack review.
8. Continue Ready Gate / WorkPlan flow.

Do not use pack import as code generation. Packs seed reviewed documentation contracts only.
