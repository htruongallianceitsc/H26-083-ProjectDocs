# Workflow 02 — Scope -> Project Blueprint

## Steps
1. Phân rã domain thành Module.
2. Phân rã mỗi Module thành Feature.
3. Lập inventory Screen/Route sơ bộ.
4. Lập inventory API sơ bộ.
5. Lập inventory DB object/integration sơ bộ.
6. Đánh dấu unknown thay vì tự thiết kế quá sớm.
7. Điền `PROJECT_BLUEPRINT.md`.

## Exit Gate
- Mọi capability in-scope phải map được vào ít nhất một Feature.
- Mọi Feature phải thuộc đúng một Module.
- Không dùng Module như container cho API/DB/Test.
