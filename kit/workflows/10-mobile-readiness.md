# Workflow 10 — Mobile Readiness

Áp dụng khi `projectTypes` có `mobile`.

## Required passes
1. Architecture + state ownership.
2. App lifecycle + process death/resume.
3. Network resilience + offline/sync.
4. Storage migration/logout cleanup.
5. Permission/native capability.
6. Navigation/deep link/push contract.
7. Realtime/background work nếu có.
8. Mobile security/privacy + SDK inventory.
9. UI states/accessibility/performance budgets.
10. Device/OS/network/lifecycle test matrix.

Chạy `npm run docs:validate` và không waive error nếu chưa có ADR/owner rõ.
