# Prompt 12 — NFR

```text
Tạo NFR cho project/feature, chỉ chọn category áp dụng:
- Performance
- Availability
- Scalability
- Reliability
- Security
- Privacy
- Accessibility
- Compatibility
- Observability
- Backup/Recovery
- Data retention
- Maintainability

Mỗi NFR phải measurable/testable khi có thể. Ví dụ dùng percentile, load, RPO/RTO, supported versions thay vì từ mơ hồ như "nhanh", "ổn định".
```
