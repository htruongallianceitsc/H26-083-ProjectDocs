# Prompt 45 — Blueprint Projection

Use when creating or refreshing a project from one Blueprint file.

1. Read `PROJECT_BLUEPRINT.md` and `kit/registry/blueprint-profiles.json`.
2. Preserve ownership: inline content may become candidates; linked content must be summarized from canonical docs.
3. Never create/overwrite canonical documents without a reviewed promotion step.
4. Select both a detail profile (`overview|lightweight|standard|full`) and audience (`general|business|developer|qa`).
5. When compiling from docs, use entity metadata, relations and verification evidence; do not invent missing relationships.
6. Report stale/conflicting ownership before reconciliation.
7. Prefer linked canonical documents when automatically reconciling.
