# Prompt 10 — Database Design

```text
Từ Feature/API/Business Rules, tạo hoặc cập nhật DB documentation.

Mỗi DB object gồm:
- purpose/owner module
- columns + type/null/default
- PK/FK
- unique/check constraints
- indexes + reason
- data lifecycle/soft-delete/retention
- sensitive fields
- expected volume/growth
- read/write APIs
- transaction/concurrency notes
- migration/backfill considerations

Phân biệt business invariant với implementation convenience.
```
