# Prompt 19 — Release Readiness

```text
Review documentation cho release <RELEASE>.

Kiểm tra:
- scope/feature list
- unresolved blocking questions
- requirement/test coverage
- API/DB migration impact
- backward compatibility
- security/privacy impact
- deployment/rollback
- monitoring/alerts
- runbooks
- known issues
- release note
- docs freshness

Output PASS / NEEDS ACTION cho từng check với evidence/reference. Không dùng điểm số tổng hợp.
```
