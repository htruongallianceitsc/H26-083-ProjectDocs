# Prompt 07 — Screen / Route / UX Contract

```text
Dựa trên Feature/Requirements hiện có, tạo Screen docs cần thiết.

Mỗi Screen phải mô tả:
- code/title/route
- accessible roles
- entry points
- page sections/components
- fields, actions, validation
- loading/success/empty/error/no-permission states
- navigation behaviour
- responsive/accessibility notes
- data sources theo API code
- feature/rule relation
- nếu có mockup: `mockup_refs`, image/state coverage và gap giữa visual evidence với canonical requirements

Không tự thiết kế API request/response trong Screen doc.
Nếu Screen được tạo từ mockup, chỉ coi mockup là design evidence; phần không nhìn thấy phải là TBD/Open Question, không suy diễn thành rule/API/permission.
```
