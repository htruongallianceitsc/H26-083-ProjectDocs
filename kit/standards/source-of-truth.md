# Source of Truth Rules

| Information | Canonical document |
|---|---|
| Product scope | Product Scope |
| Feature intent & flow | Feature |
| Testable functional need | Requirement |
| Business constraint | Business Rule |
| Raw UI image / visual snapshot | `mockups/` (design evidence, not behavioural truth) |
| UI states/actions/route | Screen |
| HTTP contract | API |
| Schema/index/ownership | Database Object |
| Cross-cutting technical rule | Architecture |
| Why a significant choice was made | ADR |
| Runtime recovery steps | Runbook |

Nếu một thông tin xuất hiện ở nơi không canonical, chỉ tóm tắt ngắn và reference nguồn canonical.

Mockup chỉ xác nhận visual evidence. API/DB/hidden rule/permission không được suy ra từ mockup nếu chưa có nguồn canonical khác.
