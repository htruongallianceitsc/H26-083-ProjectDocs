# AUTH Standard Capability Pack

Reusable authentication documentation baseline.

## Required features

- Login
- Logout
- Forgot Password
- Reset Password

## Optional features

- Register
- Google Login
- Email Verification
- Session Restore
- Single-Flight Token Refresh
- Mobile Secure Session Storage

The mobile optional features were added in v1.1.0. Select them only for projects that need those runtime concerns; the same pack remains usable for web/API-oriented AUTH documentation.

Preview before import and review all project-specific session/security variables before approval.
