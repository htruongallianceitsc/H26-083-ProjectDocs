# Pattern Packs

Patterns capture repeated implementation/documentation shapes without claiming reusable business semantics.

Mobile/RN library:
- `app-bootstrap`
- `api-auth-refresh`
- `async-screen-state`
- `list-pagination-refresh`
- `lifecycle-reconciliation`
- `connectivity-aware-query`
- `secure-session-storage`
- `socket-reconnect-rejoin`

`common-crud-pattern` remains available for generic CRUD structure.
