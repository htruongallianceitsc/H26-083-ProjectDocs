# Web UI/UX Standard

## Mục tiêu
Áp dụng cho mọi project thuộc profile này. Đây là policy/checklist production; tài liệu feature chi tiết chỉ reference standard, không copy toàn bộ rule.

## Rule bắt buộc
- Responsive breakpoints và layout behavior phải có rule chung.
- Keyboard navigation, focus order, semantic HTML và WCAG target phải được xác định.
- Form phải có validation timing, server error mapping, unsaved-change behavior.
- Table/list phải có pagination/filter/sort/search/empty/loading/error states.

## Evidence mong đợi
- Blueprint/architecture hoặc entity docs reference standard này.
- Test/release checklist cover các rule áp dụng.
- Exception phải có ADR.
