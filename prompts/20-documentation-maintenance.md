# Prompt 20 — Documentation Maintenance

```text
Audit độ tươi của tài liệu project sau một batch thay đổi/release.

Hãy tìm:
- path/route/API/table đã đổi nhưng Blueprint chưa đổi
- entity relation bị đứt
- docs có duplicate conflicting facts
- ADR bị rewrite thay vì superseded
- tests không còn khớp requirement
- runbook/monitoring không còn khớp architecture
- open question đã được trả lời nhưng chưa đóng

Đề xuất danh sách update cụ thể theo file và lý do.
```
