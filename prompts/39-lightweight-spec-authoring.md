# Prompt 39 — Author a Lightweight Feature Spec

Create or update a canonical `type: feature` document with `spec_level: lightweight`.

Keep only enough information for a mock/POC/prototype to be implemented without guessing:
- Business Goal;
- Actors;
- Main Flow;
- Key Rules;
- Technical Impact when known;
- Acceptance Summary;
- Assumptions / Known Limitations;
- Open Questions.

Do not create separate Requirement, Test, API, Screen or DB entities unless the information is already known and materially useful. Preserve stable Feature code so the same Feature can later be promoted instead of recreated.
