# Prompt 13 — Test Design

```text
Tạo Test Cases từ Requirements và Business Rules của <FEATURE_CODE>.

Bao phủ:
- happy path
- validation
- boundary
- permission/auth
- business rule positive/negative
- API errors/timeouts
- duplicate/idempotency
- concurrency nếu áp dụng
- empty/data volume
- browser/device/accessibility nếu áp dụng

Mỗi Test Case phải link tới Requirement/Rule mà nó verifies.
Cuối cùng tạo coverage matrix và chỉ ra gaps.
```
