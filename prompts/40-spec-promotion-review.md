# Prompt 40 — Promote Specification Depth

Review a Feature that is moving from Lightweight → Standard or Standard → Full.

1. Run/read the `spec:promote` gap report.
2. Re-read current Feature and relevant project context.
3. Add only missing canonical documentation needed by the target profile.
4. Preserve Feature code and existing relations/provenance.
5. Do not invent requirements to satisfy a numeric gate.
6. Resolve or explicitly retain Open Questions.
7. Re-run `spec:check`, Ready gate, freshness/impact as appropriate.
8. Apply the promoted `spec_level` only when target-level gaps are cleared.
