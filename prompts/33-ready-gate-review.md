# Prompt 33 — Ready Gate Review

Before creating or submitting an implementation WorkPlan:

1. Resolve the target Feature.
2. Read its direct related entities.
3. Run documentation validation and the Ready gate.
4. If the gate fails, remediate documentation rather than bypassing the check.
5. Report every failed condition with the exact entity/status/relation causing it.
6. Only proceed to WorkPlan authoring when Ready passes.
