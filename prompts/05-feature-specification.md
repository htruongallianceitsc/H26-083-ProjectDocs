# Prompt 05 — Feature Specification

```text
Tạo Feature Spec cho <FEATURE_CODE> bằng templates/feature-template.md.

Hãy đọc Module, related Requirements/Rules/Screens/APIs hiện có trước.
Bao gồm:
- Business goal
- Actors
- Preconditions
- Trigger
- Main flow
- Alternative/error flows
- Permissions
- Data involved
- Dependencies
- Edge cases
- Acceptance summary
- Related entities
- Open questions

Không copy chi tiết API/DB; chỉ reference canonical docs.
```
